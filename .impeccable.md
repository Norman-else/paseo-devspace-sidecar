## Design Context

### Users
The project owner is a developer reviewing changes made by a VPS coding agent in a Mac DevSpace worktree. The job is to inspect the current task's actual file changes without identifying infrastructure or choosing from unrelated workspaces.

### Brand Personality
Use Paseo's existing visual language: restrained, precise, and familiar. Let the host theme provide the colors and typography. This is an editor sidebar, not a standalone dashboard.

### Aesthetic Direction
The owner's Claude Code screenshot is the review reference: one continuous document containing every file's diff, with a compact flat file index on its right. Use understated file headers, collapsible code sections, old/new line gutters, syntax highlighting, green/red change backgrounds, and reviewed markers. Paseo supplies the surrounding chrome and theme. Avoid directory trees, workspace cards, implementation identifiers, and navigation to a separate page for each file.

### Design Principles
- Resolve the active task automatically; missing context gets a concise explanation rather than a global picker.
- Keep all file diffs in one continuous review surface; a flat right-hand index scrolls to a file in that same document.
- Only show the composer entry for a session that actually uses DevSpace.
- Show the branch and changes first; paths and infrastructure are secondary.
- Match the host language and theme. Wrap long code automatically at the available width without horizontal scrolling; keep original line numbers on the first visual line.
